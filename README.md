# CSROI

Аналитика окупаемости кейсов Counter-Strike 2. Каталог берётся из ByMykel, цены и история продаж — из Skinport. Запросы к API читают Postgres и в Skinport не ходят.

## Запуск

Порт 5432 на компьютере часто занят другим Postgres, поэтому контейнер открыт на 5433.

```bash
docker compose up -d postgres redis
uv sync
uv run alembic upgrade head
uv run python -m app.jobs.load_catalog
uv run python -m app.jobs.sync_prices
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Документация ручек: http://127.0.0.1:8000/docs

## Воркер

Сбор цен запускайте одним процессом. Второй воркер или параллельный `uv run python -m app.jobs.sync_prices` упирается в лимит Skinport: 8 запросов за 5 минут. Замок в Redis не даст второму процессу начать сбор, пока первый не закончит.

```bash
uv run python -m app.jobs.worker
```

Цены обновляются каждые 5 минут. Каталог — раз в сутки в 03:10 UTC и один раз при старте воркера.

Миграции можно запускать из нескольких процессов сразу: `alembic upgrade head` берёт advisory lock в Postgres, поэтому `api` и `worker` в docker compose не мешают друг другу.

## Ручки

- `GET /api/v1/health` — состояние базы и Redis. Без базы ручка отвечает 503. Без Redis отвечает 200 со статусом `degraded`, потому что API читает только Postgres.
- `GET /api/v1/cases` — список кейсов. Параметры: `crate_type` (по умолчанию `Case`), `sort` (`name`, `case_price`, `expected_value`, `unboxing_roi`, `roi_7d`, `roi_30d`, `roi_90d`) и `order` (`asc` или `desc`). Кейсы без значения в поле сортировки идут в конце.
- `GET /api/v1/cases/{id}` — кейс с предметами, шансами и ценами. В ответах кейсов поле `prices_updated_at` показывает, когда цена кейса обновлялась в последний раз: старая дата значит, что данные устарели.
- `GET /api/v1/cases/{id}/history?days=90` — дневные снэпшоты цены кейса. Воркер сохраняет первую цену за сутки по UTC: медиану лотов Skinport, поэтому она может отличаться от `case_price`, который считается по `suggested_price`.

Кейсы с лучшим ROI при открытии:

```bash
curl "http://127.0.0.1:8000/api/v1/cases?sort=unboxing_roi&order=desc"
```

## Как считается ROI

- Шансы — официальные шансы Valve: Mil-Spec 79.92%, Restricted 15.98%, Classified 3.2%, Covert 0.64%, нож или перчатки 0.26%. Внутри редкости шанс делится между записями пула поровну.
- Допущение, не подтверждённое Valve: каждая фаза Doppler и Gamma Doppler — отдельная запись пула с равным шансом. Так фазы перечислены в ByMykel, но списков ножей в `items_game.txt` нет, поэтому проверить это по первоисточнику не удалось. На Skinport у фаз одно имя и одна цена, поэтому у Doppler-ножа шанс в 5–7 раз выше, чем у других скинов того же ножа. От этого допущения сильно зависит ROI кейсов с Doppler, например Prisma, Gamma и Chroma, поэтому их места в рейтинге приблизительны.
- Цена предмета — медиана продаж на Skinport за 30 дней. Если продаж не было, берётся медиана за 90 дней, а затем цена лота. Цены лотов для дорогих редких предметов ненадёжны: `suggested_price` у Doppler-ножей бывает в 5 раз выше медианы продаж.
- Износ — Field-Tested, если для него есть цена. Иначе берётся износ, который занимает большую часть float-диапазона скина: у Doppler (0–0.08) это Factory New.
- Цена кейса — по текущим лотам: `suggested_price`, затем медиана и минимум лотов.
- `unboxing_roi = (EV − (цена кейса + ключ)) / (цена кейса + ключ)`. StatTrak не учитывается.
- Цена ключа задана в USD, поэтому приложение запускается только с `SKINPORT_CURRENCY=USD`.

## Проверки

```bash
make check
```

Команда запускает `ruff format`, `mypy --strict`, `ruff check --fix`, `deptry` и `pytest`. Разовые скрипты проверки источников лежат в `scripts/probes` и в проверки не входят.
